학점 영역은 서로 겹치므로 세부 부족 학점을 합산하지 않는다. 교육·상담은 기록이 있는 학기·학년을 각각 한 번만 센다.

## 가상 사례 회귀 검증

- D03은 자료구조 `CD0062`와 `GA3006`을 모두 기록했을 때 필수 요건 충족과 인정 학점을 각각 한 번만 반영하는지 확인한다.
- D04는 두 필수 과목에 `F` 기록이 합계 3회 있을 때 미이수 과목 수가 2개인지, 해당 과목 식별자가 맞는지 확인한다.

D01~D04 사례의 전체 입력과 기대값은 공개 이슈 댓글에 표가 첨부되면 옮긴다. [이슈 #40][issue]
