# 공식 출처 주소 목록

채팅 인용 카드의 `공식 원문 보기` 링크로 내보내도 되는 주소를 적는 곳이다. 저장소에는 가상 규정만 있고, 실제 문서의 주소는 저장소 밖 목록 파일의 `source_url`로 들어온다. 그 값을 고를 때 이 표를 본다.

이 표는 약국의 조제 기록부와 같다. 약사가 직접 확인한 약만 이름과 날짜를 적고 내주듯, 사람이 직접 열어 본 주소만 적는다.

## 적는 조건

- 주소가 `https://`로 시작하고 호스트(주소에서 서버 이름 부분)가 `kumoh.ac.kr`이거나 그 하위다.
- 주소가 있는 줄은 확인일이 꼭 있어야 한다. 확인일은 사람이 그 주소를 연 날이다.
- 주소가 있는 줄은 아래 두 칸을 나눠 채운다. 문서가 나온 해와 그 문서로 판정할 수 있는 입학연도는 서로 다르기 때문이다.
  - **발행·적용 학년도** — 문서 자체가 말하는 해다. `2026학년도`, `2026학년도 2학기`, `2026-07-30 원본`처럼 적는다. 해마다 바뀌지 않는 안내 페이지는 `공통 안내`로 적는다.
  - **입학연도별 판정 범위** — 그 문서가 어느 입학연도의 기준을 나눠 적었는지다. 문서에서 확인하지 못했으면 `확정하지 않음`으로 적고, 어느 문서를 따르는지 덧붙인다.
- 둘 중 하나라도 모르는 문서는 발행·적용 학년도·주소·확인일 칸에 `확인 필요`만 적는다. 주소를 적지 않으며, 확인하기 전에는 `source_url`로 쓰지 않는다.
- 이 문서에는 표의 주소 칸 말고 다른 곳에 주소를 적지 않는다. 표 밖에 적은 주소는 확인을 거쳤는지 알 수 없기 때문이다.

확인도 두 가지를 나눠 적는다.

- **응답 확인** — 주소로 요청을 보내 받은 응답 상태와 파일 형식이다. 주소가 살아 있다는 것만 말한다.
- **내용 확인** — 문서를 읽고 무엇을 대조했는지다. 응답 확인만으로는 채워지지 않는다.

`api.tests.test_deploy_doc_chat`이 표의 주소마다 서버의 주소 검사(`api/local_serve.py`의 `_check_source_url`)와 호스트 조건, 학년도·판정 범위·확인일 칸을 확인한다. 테스트는 글자의 모양만 본다. 링크를 열어 내용을 확인하는 일은 사람이 한다.

## 쓸 때 주의할 점

- 발행·적용 학년도를 입학연도로 읽지 않는다. 2026학년도 문서라고 2026학년도 입학생만 다루는 것도, 모든 입학생을 다루는 것도 아니다. 판정 범위 칸을 본다.
- 판정 범위가 `확정하지 않음`인 줄은 링크로 안내할 수 있지만, 학점 같은 숫자 기준의 근거로는 쓰지 않는다. 숫자 기준은 판정 범위가 적힌 문서의 해당 쪽에서 가져온다.
- 편입·복학·휴학처럼 예외가 있는 경우는 표의 구분만으로 판정하지 않고 `확인 필요`로 답한다.

## 다시 확인할 때

- 학교 누리집은 개편되면 주소가 바뀌고, 수정본이 올라오면 첨부 번호와 쪽 번호가 달라진다. 졸업 체크처럼 이 주소를 쓰는 기능을 내기 전에 다시 열어 보고 확인일을 고친다.
- 문서가 사라졌거나 내용이 달라졌으면 발행·적용 학년도·주소·확인일 칸을 `확인 필요`로 되돌린다.
- 새 문서는 위 조건을 채운 뒤 한 줄을 더한다.
