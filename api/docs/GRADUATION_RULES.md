학점 영역은 서로 겹치므로 세부 부족 학점을 합산하지 않는다. 교육·상담은 기록이 있는 학기·학년을 각각 한 번만 센다. 재수강은 동일 대체 과목까지 묶어 가장 최근 학기 성적으로 이수 여부와 인정 학점을 판정한다. 최종 성적이 `F`면 앞선 합격의 학점도 인정하지 않는다.

## 가상 사례 회귀 검증

네 사례 모두 8학기 과정이며 2025-03-01에 4학기가 남아 마일리지 기준은 500점이다. 교양필수 4학점, 교양선택 16학점, 수학·기초과학 영역 16학점을 이수했고 논문 합격, 취업진로교육 8회, 사례에 따로 적은 과목 외의 필수 과목 이수를 가정한다. 전공필수 판정에는 가상 사례의 필수 기록을 사용한다. 실제 전체 전공필수 목록은 확인이 필요하다. [이슈 #40 가상 검증표][cases]

- **D01** — 총 132학점, 전공 76학점, 평점 3.31, 상담 4회, 승인 510점, 필수 과목 `F` 0회. 검사 항목을 모두 충족한다.
- **D02** — 총 130학점, 전공 75학점, 평점 3.06, 상담 3회, 승인 480점, 필수 과목 `F` 0회. 상담 1회와 마일리지 20점이 부족하다. 토익 805점과 정보처리기사 자격은 승인점수에 합산하지 않는다.
- **D03** — 총 132학점, 전공 75학점, 평점 2.83, 상담 4회, 승인 510점. 자료구조 `CD0062`의 2024-1학기 `F`와 동일 대체 과목 `GA3006`의 2026-1학기 `B+`는 한 과목으로 판정한다. 같은 학기 선택 과목 영상처리 `GA3023`의 `F`까지 과거 `F`는 2회다. 남은 필수 과목은 0개이며 자료구조 학점을 한 번 인정한다.
- **D04** — 총 130학점, 전공 75학점, 평점 2.42, 상담 4회, 승인 620점. 2024-1학기 `CD0062`, 2025-1학기 운영체제 `GA3020`, 2026-1학기 동일 대체 과목 `GA3006`의 `F`가 총 3회다. 남은 필수 과목은 자료구조(`GA3006`)와 운영체제(`GA3020`) 2개다.
